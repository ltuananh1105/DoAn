# User Stories

## Documentation Note

Các User Story này được formalize retrospectively từ implemented requirements và workflows của LearnUp.

Không có evidence rằng các User Story này đã được quản lý bằng Jira hoặc một Agile backlog chính thức trong quá trình phát triển ban đầu.

---

## EPIC-01 — Course Publishing

### US-01 — Manage Course Content

As a Teacher,  
I want to create and manage my Course Content,  
so that I can prepare a Course for Students.

### US-02 — Submit Course

As a Teacher,  
I want to submit my Course for Admin review,  
so that the Course can be reviewed before being published to Students.

### US-03 — Review Course

As an Admin,  
I want to review submitted Courses,  
so that I can approve or reject them before publication.

---

## EPIC-02 — Course Discovery & Enrollment

### US-04 — Discover Course

As a Guest or Student,  
I want to browse and view Published Courses,  
so that I can find Courses relevant to my learning needs.

### US-05 — Enroll in Course

As a Student,  
I want to enroll in a Published Course,  
so that I can access its Learning Content.

---

## EPIC-03 — Learning & Assessment

### US-06 — Access Learning Content

As a Student,  
I want to access Lessons in an enrolled Course,  
so that I can study the Course Content.

### US-07 — Track Learning Progress

As a Student,  
I want to view my Learning Progress,  
so that I can track my current Course completion state.

### US-08 — Complete Quiz

As a Student,  
I want to complete a Quiz and view my result,  
so that I can evaluate my learning performance.

---

## EPIC-04 — Platform Administration

### US-09 — Manage Platform Data

As an Admin,  
I want to manage supported platform data such as Users and Course Categories,  
so that I can administer LearnUp.

---

## EPIC-05 — AI-assisted Learning

### US-10 — Use AI Tutor

As an authenticated User,  
I want to send learning questions to the AI Tutor,  
so that I can receive AI-assisted English learning support.
